# Hasnain Zaidi — Portfolio (Luxury e-commerce design)

React + Vite frontend (GSAP animations) + Express/MongoDB backend.

Run: `cd backend && npm i && npm start`  |  `cd frontend && npm i && npm run dev`
Backend ko apni `.env` chahiye (PORT, FRONTEND_URL, BREVO_API_KEY, FROM_EMAIL, OWNER_EMAIL, MONGO_URI, ADMIN_KEY).
Content edit: `frontend/src/data/portfolioData.js`. Design: `frontend/src/style/portfolio.css`.
